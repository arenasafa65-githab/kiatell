سیستم مدیریت فروشگاه موبایل
════════════════════════════════

📦 محتویات بسته:
  • froshgah-mobile.html  — کل برنامه در یک فایل (بدون نیاز به نصب)

▶️ روش اجرا:
  ۱) فایل froshgah-mobile.html را با مرورگر باز کنید
     (کروم / فایرفاکس / اج / سافاری ...)
  ۲) برنامه فوراً بالا می‌آید — بدون رمز ورود، بدون صفحه خوش‌آمد

💡 نکته‌ها:
  • برنامه کاملاً آفلاین کار می‌کند و همه داده‌ها در حافظه مرورگر
    (localStorage) ذخیره می‌شود.
  • برای پشتیبان‌گیری از اطلاعات، از بخش «پشتیبان‌گیری و بازیابی»
    داخل خود برنامه استفاده کنید.

🔧 اجرای نسخه توسعه (برای شخصی‌سازی کد):
  npm install
  npm run dev       → حالت توسعه روی http://localhost:5173
  npm run build     → خروجی نهایی در پوشه dist
